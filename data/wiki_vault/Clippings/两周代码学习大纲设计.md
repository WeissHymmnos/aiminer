### Day 3–4：时间序列建模（ARMA / GARCH / 协整）

**概念** ：ARMA/ARIMA 记住直觉——AR是历史自身的自回归，MA是历史扰动的加权。ADF平稳性检验和协整关系的含义（两个非平稳序列的线性组合平稳）。GARCH的核心是波动率聚集， $\sigma_t^2$ 依赖历史波动和历史扰动。这些在研报中出现频率极高。

**代码** ： `statsmodels.tsa` 的 `adfuller` 、 `coint` 、 `ARIMA` ； `arch` 库的 `arch_model` 。挑豆粕/豆油做协整检验画残差；对沪深300收益率跑GARCH(1,1)画条件波动率。

### Day 5–6：期权定价与希腊字母

**概念** ：BSM不要手推，记五个输入（S, K, r, σ, T）和直觉——期权价值=内在价值+时间价值。希腊字母当敏感度理解：Delta对标的、Gamma对Delta变化、Vega对波动率、Theta对时间。隐含波动率=让BSM价格等于市场价的σ，数值求解。波动率微笑是"现实中σ不是常数"的事实。SABR只要知道它是用来拟合曲面的即可，不深入。

**代码** ：手写BSM定价函数 + 五个希腊字母；用 `scipy.optimize.brentq` 反解IV；下载50ETF或300ETF期权数据，画一条隐含波动率微笑曲线。

## 第二周：组合优化 + 统计套利 + 机器学习

### Day 8–9：投资组合理论与风险度量

**概念** ：Markowitz均值-方差优化——给定目标收益最小化方差或给定风险最大化Sharpe。 **重点理解为什么实务里风险平价比均值-方差鲁棒** ——协方差矩阵稳定，期望收益不稳定。风险平价的数学：每个资产对组合波动的贡献 $w_i \cdot (\Sigma w)_i$ 相等。VaR和ES区别：分位数 vs 条件期望。最大回撤是净值的最大相对下跌。

**代码** ： `cvxpy` 做带约束的均值-方差优化（权重和为1、无做空、上限约束）；用 `scipy.optimize.minimize` 手写风险平价；对5个CTA策略的收益序列做风险平价配置vs等权对比；画有效前沿。

### Day 10–11：统计套利 + 因子模型

**概念** ：配对交易核心逻辑——两资产协整 → 残差均值回复 → 残差Z-score触发交易。Engle-Granger两步法：OLS跑对冲比率β，然后对残差做ADF。因子模型思想：收益 = 市场β + 风格因子 +... + 残差α。CTA常用因子：动量、基差、展期收益、持仓（COT）、波动率。

**代码** ：选热卷/螺纹、豆油/棕榈油做协整检验+配对交易回测；用 `statsmodels` 跑多因子OLS，对商品期货构建动量+基差因子，做分组收益和IC时序。

### Day 12–13：机器学习在CTA中的应用

**HMM** ：隐状态+观测结构，典型用于识别"牛市/震荡/熊市"三状态。不推导Baum-Welch和Viterbi，会调 `hmmlearn.GaussianHMM` 就行。

**LSTM** ：门控结构解决RNN梯度消失。金融时序上优势有限， **重点体会过拟合** ——样本内准确率80%、样本外接近50%是常态。

贝叶斯方法和模糊逻辑两周内跳过，面试问到能说出"参数是分布而不是点估计"即可。

**代码** ： `hmmlearn` 对沪深300日收益跑3状态HMM，可视化状态划分； `PyTorch` 搭两层LSTM输入20天OHLCV预测次日涨跌，亲眼验证过拟合。

### Day 14：【第二周重大进展】综合项目（二选一）🎯

**选项A（推荐，更贴近CTA实务）** ：多策略组合系统。把Day 7的趋势策略扩到8–10个品种，加上Day 10的配对交易，用风险平价做 **资产间 + 策略间** 两层配置。输出组合净值、绩效、回撤、策略相关性热力图。要能回答："为什么组合Sharpe比任一单策略都高？"

**选项B（若偏好ML方向）** ：HMM状态切换+趋势跟踪的条件策略。HMM识别趋势状态时启用均线策略，震荡状态空仓或反转。对比无状态切换版本的绩效差异。

## Day 1：期货市场机制

### 上午：概念

期货本质是 **标准化的远期合约** ，你今天约好三个月后以某价格买入某物。关键机制：

**保证金制度** 。你不用全款买一手螺纹钢，只交10%左右的保证金。所以期货天然带10倍左右杠杆——这是CTA高收益高回撤的根本原因。

**逐日盯市** 。每天收盘结算盈亏，亏到保证金不够就追加或强平。你跑回测时如果不考虑这一点，会低估极端行情下爆仓风险。

**合约规格** 。每个品种有自己的乘数、最小变动价位、交易时间、交割日。比如螺纹钢RB一手10吨、最小变动1元/吨、即每跳10元。交易所网站查得到，你需要知道的是 **计算名义价值和盈亏时要用合约乘数** 。

**基差 = 现货价 - 期货价** 。基差为正叫现货升水（backwardation），意味着持有现货比期货贵，期货贴水；基差为负叫现货贴水（contango），期货升水。商品期货的基差包含了存储成本、便利收益率、融资成本。

**展期收益** 。期货合约有到期日，你做CTA通常交易主力合约，主力切换时如果远月比近月贵（contango），你"卖近买远"展期就亏钱（展期损失）；反之backwardation下展期赚钱。历史上原油、铜这些工业品常有正展期收益，农产品不稳定。

**主力合约切换** 。国内期货的主力合约不一定是最近月，而是 **成交量和持仓量最大** 的合约。比如螺纹钢主力通常在1月、5月、10月三个合约间跳。回测时不能直接用单个合约数据，必须拼接成"主力连续合约"。

**展期调整（核心坑）** 。拼接主力连续合约时，切换日前后的价格会跳空（因为近月和远月本来就不是同一个价）。如果不调整，直接算收益率会误判一次大涨或大跌。两种标准做法： **前复权** （调整历史价格使切换日连续，最新价不变，适合作图和算技术指标）、 **后复权** （调整未来价格，历史价不变，适合算累计收益）。回测用后复权，画图可用前复权。

## Day 2：时序数据处理的硬核练习

### 上午：概念

CTA数据处理的难点不在数学，而在 **细节陷阱** 。今天目标是把这些陷阱全部踩一遍。

**时区与交易时段** 。国内期货有夜盘（21:00–次日2:30），回测用日线时把夜盘算进哪一天的数据？标准做法是夜盘归入下一交易日。akshare给的日线通常已处理好，但你要知道这回事。

**停牌、涨跌停、数据缺失** 。某天没数据是停牌还是节假日？涨跌停的收盘价是否能真实成交？回测时遇到涨跌停要假设无法开仓/平仓——这是常被忽略的一点。

**未来函数（look-ahead bias）** 。信号计算用了未来信息。最常见的坑：用 **今天收盘价** 生成的信号 **今天开盘** 就交易。你自己想一下就知道这不可能。标准做法：T日收盘生成信号，T+1日开盘（或收盘）执行。 **所有回测绝不能违背这条** 。

**生存偏差** 。研究股票时选了当前还存在的公司，忽略了已退市的——CTA里品种稳定，这个问题不严重，但换月时要注意别只用当前主力往前拼，忘了以前的主力。

## Day 3：ARMA族模型

### 上午：概念

**平稳性** 。时间序列的均值、方差、自协方差不随时间变化。价格序列通常非平稳（有趋势），收益率序列近似平稳。所有ARMA类模型的前提是平稳，对价格建模前先差分或取收益率。

**ADF检验** 。原假设是"存在单位根"（即非平稳），p值小于0.05拒绝原假设，认为序列平稳。你只需要会调 `statsmodels.tsa.stattools.adfuller` 并解读p值。

**AR(p)模型** ： $X_t = c + \phi_1 X_{t-1} + ... + \phi_p X_{t-p} + \epsilon_t$ 。"当前值依赖过去p期自身"。

**MA(q)模型** ： $X_t = \mu + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}$ 。"当前值依赖过去q期的白噪声扰动"。

**ARMA(p,q)** 就是两者相加。 **ARIMA(p,d,q)** 是先做d次差分再ARMA，处理非平稳序列。

**阶数识别** 。看ACF（自相关函数）和PACF（偏自相关函数）图：AR(p)的PACF在p阶截尾、ACF拖尾；MA(q)的ACF在q阶截尾、PACF拖尾；ARMA两者都拖尾。实务中直接网格搜索AIC/BIC最小的(p,q)组合。

**对CTA的意义** 。金融收益率的ACF通常很弱（弱有效市场），纯ARMA预测收益率效果差。但ARMA是后续GARCH的底座，也是你理解所有时序建模的起点。

## Day 4：GARCH与波动率建模 + 协整

### 上午：概念

**ARCH效应** 。收益率本身自相关弱，但 **收益率平方** 自相关强——大波动后面大概率跟着大波动，小波动后面跟着小波动。这叫 **波动率聚集** 。

**ARCH(q)** ： $\sigma_t^2 = \omega + \alpha_1 \epsilon_{t-1}^2 + ... + \alpha_q \epsilon_{t-q}^2$ 。条件方差依赖过去q期扰动平方。

**GARCH(p,q)** ： $\sigma_t^2 = \omega + \sum_i \alpha_i \epsilon_{t-i}^2 + \sum_j \beta_j \sigma_{t-j}^2$ 。再加上过去p期条件方差自身。 **GARCH(1,1)足以拟合大多数金融序列** ，工业界用烂了。

约束： $\alpha + \beta < 1$ （保证无条件方差存在）， $\alpha + \beta$ 越接近1波动率越"持久"（今天大波动影响持续很久）。金融数据这个和常见在0.95以上。

**GARCH变体** 。EGARCH处理杠杆效应（坏消息比好消息对波动率影响大）、GJR-GARCH同样目的但更简洁。你知道有这些就行，CTA里GARCH(1,1)够用。

**协整** 。两个非平稳（有单位根）序列，它们的某个线性组合是平稳的，则称二者协整。经济直觉：两个品种长期有"均衡关系"，短期偏离但会回归。配对交易的理论基础。

**Engle-Granger两步法** ：

1. 对两序列做OLS回归 $Y_t = \alpha + \beta X_t + \epsilon_t$ ，得到对冲比率 $\beta$ 和残差 $\epsilon_t$ 。
2. 对残差做ADF检验，拒绝单位根则协整。

更严格的方法是Johansen检验，支持多变量，但两步法在CTA里够用。

## Day 5：期权定价与BSM

### 上午：概念

**期权基础** 。看涨期权（Call）给持有者 **权利但非义务** 以执行价K买入标的；看跌（Put）以K卖出。到期时Call价值 = max(S-K, 0)，Put价值 = max(K-S, 0)。

**内在价值 vs 时间价值** 。内在价值是立刻行权的收益（非负），时间价值是期权价格减去内在价值——反映"未来可能更有利"的价值，随到期临近衰减为0。

**BSM模型** 。假设标的服从几何布朗运动 $dS = \mu S dt + \sigma S dW$ ，无套利、无摩擦、连续交易，推导出欧式期权定价公式：

$$
C = S N(d_1) - K e^{-rT} N(d_2)
$$
 
$$
P = K e^{-rT} N(-d_2) - S N(-d_1)
$$
 
$$
d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}
$$

$N$ 是标准正态CDF。 **不要背公式，写成代码** 。

**五个输入** ：S现价、K执行价、r无风险利率、σ波动率、T到期时间（年化）。其中 **σ是唯一无法观察的** ——其他四个都能从市场直接读。

**希腊字母** （敏感度）：

- **Delta** $\partial C/\partial S$ ：Call的Delta在(0,1)之间，深度实值接近1、深度虚值接近0。做Delta对冲就是让组合Delta=0。
- **Gamma** $\partial^2 C/\partial S^2$ ：Delta对S的变化率。Gamma大意味着Delta变化快、对冲频率要高。ATM（平值）期权Gamma最大。
- **Vega** $\partial C/\partial \sigma$ ：对波动率的敏感度。注意Vega在教科书里常写成"波动率变1%时价格变化"。
- **Theta** $\partial C/\partial T$ ：时间衰减。买方Theta为负（时间流逝价值减少）、卖方为正。
- **Rho** $\partial C/\partial r$ ：对利率敏感度，实务中最不关心。

**隐含波动率（IV）** 。给定市场期权价格，反解BSM让理论价=市场价的σ。没有解析解，数值求解（二分法、牛顿法、Brent法）。

**波动率微笑/曲面** 。BSM假设σ是常数，但实际上从市场反推的IV在不同执行价K上不一样——通常两边高中间低呈"微笑"形（股票市场更常见"斜笑"skew）。不同到期T也有不同的IV。IV(K, T)构成的曲面就是波动率曲面。

**SABR模型** 。描述波动率曲面的参数化模型（α, β, ρ, ν四个参数），实务中用于做市和对冲。你知道它存在、用来拟合曲面即可，不深入。

### 下午：代码

手写BSM， **不要** 直接找库：

```python
import numpy as np
from scipy.stats import norm

def bsm_price(S, K, T, r, sigma, option='call'):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    if option == 'call':
        return S*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)
    else:
        return K*np.exp(-r*T)*norm.cdf(-d2) - S*norm.cdf(-d1)

def bsm_greeks(S, K, T, r, sigma, option='call'):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    delta = norm.cdf(d1) if option=='call' else norm.cdf(d1) - 1
    gamma = norm.pdf(d1) / (S*sigma*np.sqrt(T))
    vega = S*norm.pdf(d1)*np.sqrt(T) / 100  # 除以100是"每1%"
    theta_call = (-S*norm.pdf(d1)*sigma/(2*np.sqrt(T)) - r*K*np.exp(-r*T)*norm.cdf(d2)) / 365
    return dict(delta=delta, gamma=gamma, vega=vega, theta=theta_call)
```

## Day 6：趋势跟踪策略基础 + 向量化回测

### 上午：概念

**移动平均线（MA）** 。简单平均SMA、指数加权EMA。EMA对最新数据权重更大、响应更快。双均线系统：快线（短窗口）上穿慢线（长窗口）做多，下穿做空。经典参数如5/20、20/60。

**布林带** ：中轨=MA(N)、上下轨=中轨±k\*std(N)。N常用20、k常用2。突破上轨做多/突破下轨做空是趋势策略；反向操作（触上轨做空）是均值回归策略。 **同一个指标在不同品种/时段表现不同** ，这是CTA的核心难题。

**唐奇安通道** ：N日最高价和最低价。向上突破N日新高做多——这就是海龟交易法则的核心。

**ATR（Average True Range）** 。真实波幅TR = max(H-L, |H-C\_prev|, |L-C\_prev|)，ATR = N日TR均值。用于衡量波动幅度，做止损（比如2\*ATR止损）和头寸管理（波动率目标）。

**动量因子** 。过去N日收益率或(收盘/N日前收盘 - 1)。截面动量是不同品种按动量排序多空top/bottom，时序动量是单品种动量为正做多、为负做空。CTA主流是时序动量。

**突破策略 vs 均线策略** 。均线是平滑信号有滞后，突破对价格反应更快但假突破多。实务中常组合使用。

**过滤机制** 。趋势策略在震荡市亏钱，所以加过滤：用ADX判断趋势强度、用波动率过滤（低波动时不交易）、用宏观状态过滤（HMM识别的状态）。

**头寸管理** 。同样信号下开多少仓？等权是最差的，因为不同品种波动差异巨大。 **波动率目标** 是标准做法：目标每个品种对组合贡献相同的风险，仓位 = 目标波动 / 品种ATR。

def sma(series, window): return series.rolling(window).mean()
def ema(series, window): return series.ewm(span=window, adjust=False).mean()

def bollinger(series, window=20, k=2):
    mid = sma(series, window)
    std = series.rolling(window).std()
    return mid, mid + k*std, mid - k*std

def atr(df, window=14):
    # df需要有high, low, close
    tr1 = df['high'] - df['low']
    tr2 = (df['high'] - df['close'].shift()).abs()
    tr3 = (df['low']  - df['close'].shift()).abs()
    tr = pd.concat([tr1, tr2, tr3], axis=1).max(axis=1)
    return tr.rolling(window).mean()

def donchian(df, window=20):
    upper = df['high'].rolling(window).max()
    lower = df['low'].rolling(window).min()
    return upper, lower

**向量化回测框架** （写进 `src/backtest.py` ）：

```python
def vectorized_backtest(df, signal, cost=0.0003, slippage=0.0002):
    """
    df: 含open/close的价格数据
    signal: 目标仓位（-1/0/1），index与df对齐
    返回: 策略日收益序列和绩效
    """
    position = signal.shift(1).fillna(0)  # T日信号T+1日执行
    # 用次日开盘价的收益近似
    daily_ret = df['close'].pct_change()
    strat_ret = position * daily_ret
    # 换仓成本
    trades = position.diff().abs().fillna(0)
    cost_ret = trades * (cost + slippage)
    net_ret = strat_ret - cost_ret
    return net_ret
```

## Day 8：投资组合理论 —— 均值方差与有效前沿

### 上午：概念

**组合收益与风险** 。N个资产权重向量w（和为1），收益向量μ、协方差矩阵Σ。组合期望收益 = $w^T \mu$ ，组合方差 = $w^T \Sigma w$ 。

**均值方差优化（Markowitz, 1952）** 。给定目标收益μ₀，最小化方差：

$$
\min_w w^T \Sigma w \quad \text{s.t.} \quad w^T \mu = \mu_0, \ w^T \mathbf{1} = 1
$$

解析解存在（拉格朗日乘数法），但加上"不许做空"（w≥0）等约束后只能数值求解。

**有效前沿** 。扫描不同目标收益μ₀，得到一系列最优组合，在(σ, μ)平面画出来就是有效前沿——左上凸的曲线。曲线上每个点都是"给定风险下最高收益"或"给定收益下最低风险"的组合。

**切点组合（最大Sharpe组合）** 。有效前沿上与无风险利率连线切点的组合。它是资本市场线的切点，代表市场上Sharpe最高的风险组合。数学上：

$$
\max_w \frac{w^T \mu - r_f}{\sqrt{w^T \Sigma w}}
$$

**均值方差的致命问题** 。μ估计误差极大（回报率估计非常不稳定），Σ稳定但也有估计误差。结果是最优权重对输入极其敏感——输入变1%输出可能变50%。实务里 **纯Markowitz基本不用** ，用收缩估计、Black-Litterman、风险平价等方法。

**风险平价（Risk Parity）** 。放弃估计μ，只用Σ。思想：每个资产对组合波动率的边际贡献相等。资产i的边际风险贡献 = $w_i \cdot (\Sigma w)_i$ ，令所有i的这个值相等。

对应优化问题：

$$
\min_w \sum_i \left( \frac{w_i (\Sigma w)_i}{w^T \Sigma w} - \frac{1}{N} \right)^2
$$

没有解析解，用 `scipy.optimize.minimize` 的SLSQP求解。

**等风险贡献（ERC）** 是风险平价的别名。桥水的All Weather基金核心就是这个思想。

**其他常见方法** ：

- **最小方差组合** ：不看收益，只最小化方差。
- **等权组合** （1/N）：朴素但鲁棒，DeMiguel等人的论文证明它在样本外常打败Markowitz。
- **Black-Litterman** ：用贝叶斯框架结合"市场隐含收益"和"主观观点"。

### 下午：代码

`cvxpy` 是凸优化神器，语法直观：

```python
import cvxpy as cp
import numpy as np

def markowitz_max_sharpe(mu, Sigma, rf=0.0):
    N = len(mu)
    y = cp.Variable(N)  # 变量替换技巧：y = w/kappa
    kappa = cp.Variable()
    constraints = [
        (mu - rf) @ y == 1,  # 归一化约束
        cp.sum(y) == kappa,
        y >= 0,
        kappa >= 0
    ]
    prob = cp.Problem(cp.Minimize(cp.quad_form(y, Sigma)), constraints)
    prob.solve()
    w = y.value / kappa.value
    return w

def min_variance(Sigma):
    N = Sigma.shape[0]
    w = cp.Variable(N)
    prob = cp.Problem(cp.Minimize(cp.quad_form(w, Sigma)),
                      [cp.sum(w) == 1, w >= 0])
    prob.solve()
    return w.value
```

风险平价用 `scipy` ：

```python
from scipy.optimize import minimize

def risk_parity(Sigma):
    N = Sigma.shape[0]
    def objective(w):
        port_var = w @ Sigma @ w
        mrc = Sigma @ w
        rc = w * mrc
        target = port_var / N
        return np.sum((rc - target)**2)
    
    cons = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
    bounds = [(0, 1) for _ in range(N)]
    w0 = np.ones(N) / N
    res = minimize(objective, w0, method='SLSQP', 
                   bounds=bounds, constraints=cons)
    return res.x
```

## Day 9：风险度量与策略组合

### 上午：概念

**VaR（Value at Risk）** 。置信水平α下（通常95%或99%）的最大损失： $P(L > VaR_\alpha) = 1 - \alpha$ 。三种算法：

- 历史模拟：历史收益率的分位数。
- 参数法（假设正态）： $VaR = \mu + z_\alpha \sigma$ 。
- 蒙特卡洛：模拟大量路径取分位数。

VaR的缺陷：不满足次可加性（组合VaR可能大于单个VaR之和，违反"分散化降低风险"的直觉），且不告诉你"超过VaR时平均亏多少"。

**ES（Expected Shortfall / CVaR）** 。超过VaR的条件期望损失： $ES_\alpha = E[L | L > VaR_\alpha]$ 。满足次可加性，是 **一致风险度量** （coherent risk measure）。监管上Basel III从VaR切到ES。

**最大回撤（MDD）** 。净值从历史峰值到谷值的最大跌幅。CTA里这是最被关注的指标之一，因为投资者对连续亏损的容忍度远低于对波动率的。

**Calmar比率** = 年化收益 / |MDD|。和Sharpe互补——Sharpe是平均表现，Calmar关注尾部。

**信息比率（IR）** = (策略收益 - 基准收益) / 跟踪误差。CTA常用Sharpe替代，因为多数CTA无明确基准。

**策略间相关性与组合效果** 。两个策略各自Sharpe=1，相关性=0.5，等权组合Sharpe ≈ $1 \cdot \sqrt{2/(1+0.5)} ≈ 1.15$ ；相关性=0，Sharpe ≈ $\sqrt{2} ≈ 1.41$ ；相关性=-0.5，Sharpe ≈ $\sqrt{2/0.5} = 2$ 。 **低相关性是组合的圣杯** 。

## Day 10：统计套利 —— 配对交易

### 上午：概念

**配对交易核心逻辑** 。两个协整的资产，spread（= A - β\*B）围绕均值波动。当spread异常高（Z-score > +2），做空A、做多B（期待spread回归）；Z-score < -2时反向。Z-score回到0附近平仓。

**对冲比率β的估计** 。

- **OLS回归** ： $A = \alpha + \beta B + \epsilon$ ，用历史数据估计。问题是β可能随时间变化。
- **滚动OLS** ：用过去N日数据估计β，每天更新。平衡参数稳定性和适应性。
- **卡尔曼滤波** ：把β看作隐变量，动态估计。更rigorous但对初学者不必上。
- **TLS（total least squares）** ：OLS假设B是解释变量无误差，TLS对称处理。

**z-score信号** ： $z = (spread - \mu_{spread}) / \sigma_{spread}$ ， $\mu$ 和 $\sigma$ 用滚动窗口（比如60日）。入场阈值±2、出场阈值0、止损阈值±3是经典参数。

**协整失效** 。协整关系可能断裂（比如宏观结构变化、品种间逻辑改变）。实务中要定期（比如每月）重新检验协整，失效则停止交易该对。

**Hurst指数** 。判断序列均值回归/随机游走/趋势：H<0.5均值回归，H=0.5随机游走，H>0.5趋势。配对交易要求spread的H<0.5。

**半衰期（half-life）** 。均值回归速度的度量。对spread拟合AR(1)： $spread_t - spread_{t-1} = \lambda (\mu - spread_{t-1}) + \epsilon$ ，半衰期 = ln(2)/λ。半衰期太长（比如>60日）说明回归太慢，交易频率低、资金占用久，不划算。

**配对交易的常见坑** ：

- 看似协整但实际是虚假回归（两个都有相同的时间趋势）。
- 一次大偏离后永不回归——β变了或基本面变了。
- 高频切换：Z-score在阈值附近抖动，频繁开平仓手续费吃完利润——实务中加"确认期"或使用平滑z-score。

def pair_trading_backtest(price_a, price_b, lookback=60, entry=2.0, exit=0.5, stop=3.5):
    # 1. 滚动OLS计算β
    beta = rolling_ols_beta(price_a, price_b, lookback)
    # 2. spread和z-score
    spread = price_a - beta * price_b
    z = (spread - spread.rolling(lookback).mean()) / spread.rolling(lookback).std()
    # 3. 信号生成（注意状态机）
    position = generate_pair_signal(z, entry, exit, stop)
    # 4. 组合收益
    ret_a = price_a.pct_change()
    ret_b = price_b.pct_change()
    # 做多A做空B时，组合收益 ≈ ret_a - beta*ret_b（忽略β变化的二阶项）
    spread_ret = ret_a - beta.shift(1) * ret_b
    strat_ret = position.shift(1) * spread_ret
    return strat_ret, position, z
```

def generate_pair_signal(z, entry, exit, stop):
    position = np.zeros(len(z))
    state = 0
    for i in range(len(z)):
        if state == 0:  # 空仓
            if z.iloc[i] > entry:    state = -1  # 做空spread
            elif z.iloc[i] < -entry: state = +1  # 做多spread
        elif state == -1:  # 做空中
            if z.iloc[i] < exit or z.iloc[i] > stop: state = 0
        elif state == +1:  # 做多中
            if z.iloc[i] > -exit or z.iloc[i] < -stop: state = 0
        position[i] = state
    return pd.Series(position, index=z.index)
```

## Day 11：因子模型与多因子CTA

### 上午：概念

**因子投资思想** 。资产收益可分解为若干 **系统性因子** 的暴露和特质（alpha + 残差）。Fama-French三因子：市场、规模、价值。CTA领域常见因子：

- **时序动量** ：过去N月收益。正→做多、负→做空。
- **截面动量** ：品种间排序，买前20%卖后20%。
- **基差/carry** ：基差大的品种做多（高展期收益率）。
- **波动率** ：低波动做多、高波动做空（低波动异象）。
- **期限结构斜率** ：近月/远月价差。
- **持仓（COT）** ：商业持仓净多/净空。
- **季节性** ：某些农产品/能源品种有年内周期。

**单因子评价** ：

- **IC（信息系数）** ：因子值与未来收益的截面相关系数（Pearson或Spearman，rank IC更稳健）。每期一个IC，平均IC>0说明因子有效，IC\_IR = mean(IC)/std(IC) 衡量稳定性。
- **分组收益** ：按因子值排序分N组，看每组未来平均收益是否单调。单调+两端差异大是好因子。

**多因子合成** ：

- **等权合成** ：各因子标准化后求和。
- **IC加权** ：按历史IC大小加权。
- **最大化IR** ：求解使合成因子IC\_IR最大的权重。

**CTA因子研究 vs 股票因子研究的差异** ：股票N个截面（几千支票）、时序短；CTA截面小（几十个品种）、时序长。所以股票靠横截面、CTA靠时序+少量截面。

## Day 12：HMM状态识别择时

### 上午：概念

**HMM（隐马尔可夫模型）** 假设：

- 存在一个 **隐状态序列** $S_1, S_2, ..., S_T$ ，每个 $S_t$ 取K个离散值之一（比如"牛/熊/震荡"三状态）。
- 状态间按 **转移矩阵** $A$ 转换： $P(S_{t+1}=j | S_t=i) = A_{ij}$ 。
- 每个状态下 **观测** $O_t$ 服从特定分布（高斯HMM下是正态分布，参数随状态变化）： $O_t | S_t=i \sim N(\mu_i, \sigma_i^2)$ 。

三大问题：

1. **评估** ：给定模型参数和观测，计算 $P(O|\lambda)$ ——前向算法。
2. **解码** ：找最可能的隐状态序列 $S^*$ ——Viterbi算法。
3. **学习** ：从观测估计参数 $\lambda$ ——Baum-Welch（EM算法的特例）。

你不需要推导这些，调 `hmmlearn` 就行。要记住的是： **HMM是无监督的** ，你只给收益率序列，它自己找"有几个状态、每个状态长什么样"。

**对CTA的用法** ：

- **市场状态识别** ：对股指或商品指数跑HMM，识别牛/熊/震荡，在趋势状态启用趋势策略、震荡状态空仓或反转。
- **波动率状态** ：HMM识别低波/高波状态，高波动状态下减仓或止损收紧。
- **多维HMM** ：观测是多维（收益率、波动率、成交量变化），状态更精细。

**HMM的局限** ：

- 状态数K要自己定（AIC/BIC选择）。
- 状态的经济解释靠事后人工判断——HMM不告诉你哪个是牛市。
- 状态切换是概率的，实务中有滞后（你观测到切换时往往已进入新状态很久）。
- 过拟合风险——历史上看完美识别牛熊，样本外能力要严格验证。

## Day 13：LSTM与深度学习在CTA中的应用

### 上午：概念

**RNN/LSTM简介** 。RNN循环神经网络处理序列数据，隐藏状态 $h_t = f(h_{t-1}, x_t)$ 携带历史信息。普通RNN有梯度消失问题（长期依赖学不到）。 **LSTM** 引入门控机制（输入门、遗忘门、输出门）和单元状态C，显著缓解梯度消失。

LSTM内部（你不用推导，只要知道结构）：

$$
f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{遗忘门}
$$
 
$$
i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{输入门}
$$
 
$$
\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)
$$
 
$$
C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t
$$
 
$$
o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{输出门}
$$
 
$$
h_t = o_t \odot \tanh(C_t)
$$

**金融时序上的LSTM效果** 。诚实说：单用价量特征LSTM **很难稳定跑赢传统规则** 。原因：市场接近有效、噪声极大、样本量小（日频数据一年才250个样本）、非平稳（分布随时间漂移）。但LSTM+大量辅助特征+集成方法可以有 marginal 改进，各大私募都在做。

**你为什么还要学** ：

- 面试必问。
- 理解过拟合——亲眼看到训练集准确率80%、测试集50%的经典图景。
- 未来想做alpha因子挖掘、另类数据（文本、图像、产业链）时，深度学习是必备工具。

**过拟合的核心** 。金融ML最大的敌人是过拟合。防过拟合手段：

- 正则化：L1（稀疏）、L2（权重衰减）、Dropout。
- 早停（early stopping）：验证集损失不再下降就停。
- 简化模型：越小越好，大模型在小数据上必过拟合。
- 交叉验证：金融上用 **时序交叉验证** （walk-forward），绝不能shuffle分K折，那是未来函数。
- 样本外严格隔离：测试集只在最终评估用一次。

**标准化/归一化** 。神经网络对输入尺度敏感。对每个特征做滚动标准化（用过去N日的均值和std），避免未来函数。

### 下午：代码

用PyTorch搭个小LSTM，体会全流程。

**任务1** ：数据准备。对螺纹钢，构建输入特征（过去20日的OHLCV+若干技术指标），标签为下一日涨跌（二分类）或下一日收益（回归）。滚动标准化。

```python
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader

class TimeSeriesDataset(Dataset):
    def __init__(self, features, labels, window=20):
        self.X = []
        self.y = []
        for i in range(window, len(features)):
            self.X.append(features[i-window:i])
            self.y.append(labels[i])
        self.X = torch.FloatTensor(np.array(self.X))
        self.y = torch.FloatTensor(np.array(self.y))
    
    def __len__(self): return len(self.y)
    def __getitem__(self, i): return self.X[i], self.y[i]

class LSTMModel(nn.Module):
    def __init__(self, input_dim, hidden_dim=32, num_layers=2):
        super().__init__()
        self.lstm = nn.LSTM(input_dim, hidden_dim, num_layers, 
                            batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden_dim, 1)
    
    def forward(self, x):
        out, _ = self.lstm(x)
        out = self.fc(out[:, -1, :])  # 用最后一步的隐状态
        return out.squeeze()
```

**任务2** ：严格的时序切分——前70%训练、中间15%验证、后15%测试。 **绝不shuffle** 。

**任务3** ：训练循环（BCEWithLogitsLoss分类或MSELoss回归），Adam优化器（lr=1e-3），早停。把模型放到GPU： `model = model.to('cuda')` ，数据 `batch.to('cuda')` 。你的5070Ti跑这个小模型应该1秒1个epoch。

**任务4（最关键的实验）** ：画训练集损失和验证集损失 vs epoch的曲线。你会看到典型的过拟合——训练损失持续下降、验证损失先降后升。早停在验证损失最低点。

**任务5** ：把LSTM的预测（>0.5做多、<0.5做空）作为信号，接入Day 6的回测框架，对比Day 7的纯规则趋势策略绩效。 **诚实接受结果** ——LSTM很可能跑不过双均线。这个"诚实面对失败"的经历本身就是CTA面试时的谈资。

**任务6（加分）** ：尝试让LSTM预测波动率而非方向（方向很难、波动率相对容易），用预测的波动率做仓位管理。
