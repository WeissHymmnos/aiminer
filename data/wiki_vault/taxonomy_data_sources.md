# Taxonomy: Data Source

## Purpose

This page groups all `data_source` nodes and highlights how they relate to the research graph.

## Nodes

- [[macro_data_source]] **Macro Data Source** · `baseline` / `active` — Macro indicators and rate/inflation proxies used to contextualize or modulate factor signals.
- [[price_volume_data_source]] **Price and Volume Data Source** · `baseline` / `active` — Daily OHLCV and derived intraday anchors such as VWAP form the base layer for most experiments.
- [[sector_data_source]] **Sector and Cross-Sectional Aggregate Data Source** · `baseline` / `active` — Sector-level returns, realized volatility, and peer aggregates used for neutralization and cross-sectional context.
