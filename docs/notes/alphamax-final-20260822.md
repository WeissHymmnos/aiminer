## 方法链 (每步都可复现)
1. 候选池: alpha_pool 全库 |IC|>0.2% 真实回测因子, 负IC取反向
2. 贪心前向选择13个: 相关性<0.2约束下逐步最大化组合Sharpe
3. EWMA(halflife=3) 平滑降噪
4. Ledoit-Wolf收缩协方差 + James-Stein收缩均值 → MVO权重
5. 恒定杠杆4.1x 推到50%年化
6. 回撤熔断风控: 回撤>0.5%线性降仓, >1%降到15%仓位(规则化,无前视)

## ⚠️ 必须知道的风险
1. **样本内优化**: 权重在2018-2020全期拟合, 无真样本外。实盘预期需打折。
2. **EWMA平滑的信号延迟**: 平滑降低波动的同时引入滞后, 实盘滑点会吃掉部分收益。
3. **4.1x杠杆**: A股两融上限约1x, 需期货/期权/场外衍生品实现; 或接受低杠杆版本
   (1x杠杆=12%年化, Sharpe不变)。
4. **MDD<1%依赖熔断执行价差**: 极端跳空时熔断无法在目标位成交。
5. 因子池来自同一挖掘管线, 存在共同偏差。
