# AIMiner 周更新日志：

## 总览

项目从以研究脚本和 TUI 为主的工作流，推进到更完整的产品化闭环。核心新增包括多市场本地回测、策略反思循环、组合合成、Web 前端、Tauri 桌面壳、CI 打包、可逆工作区重置，以及更清晰的文件结构。


### Web 前端

前端新增和扩展了 AIMiner 的操作界面。它不再只是一个展示层，而是开始承接实际工作流操作，包括 Swarm 运行、运行详情、手动回测、策略回测、Alpha Pool、Wiki、Admin 操作等。


前端还补齐了 standalone Docker/Nginx 构建路径。UI 可以脱离 Vite 开发服务器，以更接近生产部署的方式运行。


### TUI

修复了 `tui.py` 显示问题。更大的基线提交继续把操作能力接入 TUI。整体趋势是：TUI 仍是本地控制面，但 Web 正在追赶并尝试形成同等能力。

## Agent、策略与组合

### 策略反思循环

策略层新增了 reflexion loop 和 walk-forward validation。这是本周研究质量层面最重要的变化之一，因为策略构建不再只是一次性 LLM 输出，而是进入“生成、批评、修正、验证”的迭代流程。


实际影响：

- 策略候选可以被生成、批评、修订，并通过 walk-forward 检查。

- Manager/workflow 可以把策略评估作为独立阶段处理。

- 配置解析、策略正确性、walk-forward 行为都有了更明确的测试保护。

### PortfolioAgent 与 Risk Parity

项目新增 `PortfolioAgent` 和 risk parity 配置层。这意味着 AIMiner 可以在因子和策略之后，再产出组合级建议，而不是停留在单个策略的评估结果上。

主要文件：

| 能力 | 文件 |
| - | - |
| 组合代理 | `agents/portfolio\_agent.py` |
| 组合配置逻辑 | `core/portfolio.py` |
| Manager 集成 | `manager.py` |
| 命令行入口 | `scripts/run\_portfolio.py` |
| 测试 | `tests/unit/test\_portfolio.py`, `tests/unit/test\_portfolio\_agent.py` |


实际影响：

- 多个策略可以被合成为组合建议。

- Risk parity 提供了确定性的配置基线，避免组合层完全依赖 LLM 总结。

- 组合输出成为可测试、可复现的独立产物。

### Manager 与工作流方向

Manager 路径进一步扩展，开始同时处理因子、策略、验证摘要和组合产物。项目正在从“多 Agent 产出文本”转向“多 Agent 产出结构化研究资产，并由评估器和 Manager 选择、合成、沉淀”。

## 回测与数据

### 多市场本地回测

分支历史先隔离实现了多市场本地回测支持，随后并入大型基线。这使评估逻辑不再绑定单一市场或单一数据路径。


### RiceQuant 指数期货下载器

新增 RiceQuant 指数期货数据下载工具：

- `scripts/download\_rq\_index\_futures.py`

- `scripts/test\_local\_futures\_data.py`

- `tests/unit/test\_rq\_index\_futures\_download.py`

这个变化把远端 RiceQuant 数据和本地回测文件连接起来，减少每次实验都临时拉取数据的需求。

### 评估与指标

基线和后续提交扩展了本地/RiceQuant 评估路径，并补充了 Rank IC、数值一致性、策略正确性等测试。

重点测试方向：

- 数值一致性

- Polars operator 行为

- RQ eval metrics

- Strategy backtester

- Manual/strategy runner integration

## API 与运行时

### FastAPI 接口面扩展

API 成为 Web/TUI 和研究引擎之间的核心桥。历史提交覆盖了以下接口方向：

- Swarm run 列表和详情

- Run 启动和运行状态

- 手动回测执行和历史

- 策略回测执行和历史

- Wiki index/page/graph

- Admin/reset 操作

- 分页 fallback 行为

前端 API client 也做了分页兼容处理，降低后端列表响应形态演进时对 UI 的破坏。

### Runtime Paths

`core/runtime.py` 和 `tests/unit/test\_runtime\_paths.py` 开始把运行路径显式化。这个变化对 Docker、Tauri、PyInstaller 和普通源码运行都很重要，因为这些环境下相对路径行为不同。

### 可逆工作区重置

新增 `scripts/reset\_workspace.py`，并接入 API/manager，同时加入单元测试。设计重点是“可逆”：重置可以保留备份，而不是直接删除状态。

实际影响：

- 可以清理本地生成物，不需要手动定位文件。

- Admin/Web/TUI 后续可以安全暴露重置能力。

- 重置行为有测试保护，减少误删风险。
